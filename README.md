# ตารางคงเหลือรับ

เครื่องคิดเลขหน้าเดียว คำนวณเงินเหลือรับต่อเดือนหลังกู้ เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## วิธีคำนวณ

เงินเดือนกับรวมรับแยกกัน

- **เงินเดือน** ใช้คิดเกณฑ์ขั้นต่ำเท่านั้น: เงินเดือน × 30% (ปรับเปอร์เซ็นต์ได้)
- **รวมรับ** ใช้คำนวณหนี้สิน:
  1. รวมรับ − รวมหักตามสลิป = คงเหลือตามสลิป
  2. + ยอดผ่อนของหนี้เดิมที่จะปิด (เช่น อทบ. สหกรณ์ออมทรัพย์)
  3. − ผ่อนงวดใหม่ต่อเดือน
  4. = **เหลือรับต่อเดือน** แล้วเทียบกับเกณฑ์ขั้นต่ำ

ตารางเงินกู้: ยอดกู้ − ยอดปิดหนี้เดิม − ค่าธรรมเนียม = **รับเงินจริง**

มีช่อง "ผ่อนใหม่ได้สูงสุด" บอกว่าผ่อนได้ไม่เกินเดือนละเท่าไหร่จึงยังผ่านเกณฑ์

## ปุ่มด้านบน

- สวิตช์ ☀️/🌙 สลับโหมดสว่าง/มืด (จำค่าไว้ในเบราว์เซอร์)
- 📷 ส่งออกเป็นรูป PNG ตัดแถวหนี้ที่ว่างออก เหลือเนื้อหาพอดี แล้วเลือก 💾 บันทึก หรือ 📋 คัดลอกรูป
- 📋 คัดลอกสรุปเป็นข้อความสำหรับส่งต่อ
- 🧹 ล้างค่าทั้งหมด (กดสองครั้ง)

## หมายเหตุ

- ค่าที่กรอกเก็บในเบราว์เซอร์ของเครื่องนั้น (localStorage) ไม่ส่งออกไปไหน
- ฟีเจอร์ส่งออกรูปใช้ไลบรารี html2canvas โหลดจาก cdnjs ต้องต่ออินเทอร์เน็ต
- ผลคำนวณใช้ประกอบการพิจารณาเท่านั้น เกณฑ์จริงขึ้นกับผู้ให้กู้แต่ละแห่ง
