# ตารางคงเหลือรับ

เครื่องคิดเลขหน้าเดียว คำนวณเงินเหลือรับต่อเดือนหลังกู้ เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## วิธีคำนวณ

1. เงินเดือน (รวมรับ) − รวมหักตามสลิป = คงเหลือตามสลิป
2. + ยอดผ่อนของหนี้เดิมที่จะปิด (เช่น อทบ. สหกรณ์ออมทรัพย์)
3. − ผ่อนงวดใหม่ต่อเดือน
4. = **เหลือรับต่อเดือน** แล้วเทียบกับเกณฑ์ขั้นต่ำ 30% ของเงินเดือน (ปรับเปอร์เซ็นต์ได้)

ตารางเงินกู้: ยอดกู้ − ยอดปิดหนี้เดิม − ค่าธรรมเนียม = **รับเงินจริง**

มีช่อง "ผ่อนงวดใหม่ได้สูงสุด" บอกว่าผ่อนได้ไม่เกินเดือนละเท่าไหร่จึงยังผ่านเกณฑ์

## หมายเหตุ

- ค่าที่กรอกเก็บในเบราว์เซอร์ของเครื่องนั้น (localStorage) ไม่ส่งออกไปไหน
- ปุ่ม "คัดลอกสรุป" สร้างข้อความสรุปสำหรับส่งต่อ
- ปุ่ม "ล้างค่า" เคลียร์ทุกช่อง
- ผลคำนวณใช้ประกอบการพิจารณาเท่านั้น เกณฑ์จริงขึ้นกับผู้ให้กู้แต่ละแห่ง
